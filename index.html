How it works

  1. In LinkedIn Recruiter (or a profile), use More → Save to PDF to export a candidate.
  2. Drop one or more of those PDFs above.
  3. Review the parsed candidates, then Download Excel.

The exported workbook has three tabs: Candidates (one row each), Experience (one row per job) and Skills (one row per candidate/skill — handy for pivoting or filtering).

Runs entirely in your browser · Built with PDF.js & SheetJS · Source on GitHub
